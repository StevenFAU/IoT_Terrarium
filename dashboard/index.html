Connecting

  1. Join the Terrarium WiFi network (password in the project summary).
  2. If the phone warns "No internet", choose Stay connected.
  3. Open 192.168.4.1 in the browser. Add it to your home screen for one-tap access.

History is kept in the board's memory, so it starts over if the board restarts. The last 40 photos and these settings survive restarts.
